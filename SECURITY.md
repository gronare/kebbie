# Security policy

## Supported versions

Only the latest release of kebbie gets security fixes. Update to it before you report, if you can.

## Report a vulnerability

Report it privately, never in a public issue:

1. Open the [Security tab](https://github.com/gronare/kebbie/security) of the repository.
2. Choose **Report a vulnerability**.
3. Describe what an attacker can do, the version you tested, and the steps that show it.

## What happens next

1. You get an answer within 3 working days saying the report has been received.
2. The fix goes out in a new release, together with a GitHub security advisory that describes the problem and the version that fixes it.
3. The advisory credits you by the name you choose, or leaves you out if you prefer.
