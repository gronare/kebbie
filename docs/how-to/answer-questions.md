# Answer a task's questions

![Answering a task's question in the inbox, with a comment](../assets/clips/answer-questions.gif)

Tasks ask you through the board, with options and a recommendation. Answer them all in one window.

1. Press `i` on the board. The inbox opens with the waiting questions on the left and the selected question's detail or plan in the middle.

2. Pick an option with `↑` `↓`. The cursor starts on the recommended one, marked `recommended`.

3. To add a comment, start typing, or `tab` to the comment field. To answer in your own words, select "In my own words" and write the answer as the comment.

4. Press `⏎`. The answer reaches the task as `[from you] <answer>`, and the lead gets a copy.

For a plan, the options are approve, approve with a comment, ask for changes, and reject with a comment. `PageUp` and `PageDown` scroll the plan.

`g` jumps to the asking task's Space. When you settle a question there instead, close it on the board with:

```bash
kelpie answered billing
```
