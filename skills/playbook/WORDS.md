# Words the user reads

Every text an agent writes for the user (a plan brief, a question, the top of a card, a decision line, a report line) is read **cold**: on the phone or the board, between other tasks, by someone who did not see your session and acts on what the first line says. These rules hold for each of those texts; the skill for each text adds its shape.

- **Language.** Write in the vault's language: the language its notes are written in. Without a vault, the language the user writes to you in. kebbie's own words stay as kebbie writes them: the card's labels (`Built:`, `Decisions:`, `Also noticed:`), who decided (`you`, `lead`, `task`, `investigator`) and `nothing` as a report's next.
- **Front-load.** The first words carry the point: what the user gets, decides or does. What led there comes after, or stays out.
- **Short sentences.** About 15 words, one idea each. A sentence past 25 words is two sentences.
- **The user's words.** Name a thing the way the user meets it: the page, the button, the row, the command he types, the name he gave it. A word from the code goes in only when he used it himself.
- **The result.** Say what works, or will work, from his side; a number he felt before (a three-second stall) may stand beside the new one. How it was found, the code it replaced and what was tried live in the note and the commits.
- **The machinery stays in the note.** Shas, commit ids, branch names, file paths, flags, test names, counts of commits or subtasks, dates and clock times, and kebbie's inner parts (worktree, investigator, a task's half) belong to the note, the commits and the push window. A command or a path is in the text only when it is the thing the user will type or open.
- **A link once, at the end.** A mock, a pull request or a page is its address, once, after the last sentence. kebbie turns it into a row the user taps.
- **Once.** Each thing is said in one place: what the title says, the body does not say again, and a thing under one part of a text is not repeated under another. What the user asked for is his already, so the text says what he gets beyond his own words.

Done when you have read the text as the user would on his phone and each sentence holds every rule: he can act on the first line alone, and every word after it is one he would miss.
